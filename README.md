# Drum Synth

A web-based drum synthesizer inspired by classic Roland drum machines like the TR-606 and TR-808. This project recreates the iconic sounds and interface of vintage drum machines, featuring authentic kick, snare, hi-hat etc sound synthesis. The synth provides real-time parameter control through interactive knobs, allowing users to shape and customize each drum sound just like the original hardware. Built entirely in the browser, it offers the nostalgic experience of classic drum programming without requiring any plugins or downloads.

## Technologies Used

- **Web Audio API** - Real-time sound generation and processing, creating authentic analog-style drum sounds through oscillators, filters, and envelope generators
- **Alpine.js** - Reactive data binding and component management for smooth real-time parameter updates
